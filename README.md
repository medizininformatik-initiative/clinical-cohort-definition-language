The Clinical Cohort Definition Language (CCDL) provides a formal definition for cohort queries based on inclusion and exclusion criteria.

This repository includes:
* an example of a CCDL (as JSON file)
* a JSON schema describing the CCDL
* a python script that generates CCDLs that fit to custom test data

For the full documentation, including the CCDL definition and the CCDL generator usage, please refer to the [official documentation](https://medizininformatik-initiative.github.io/clinical-cohort-definition-language/).
